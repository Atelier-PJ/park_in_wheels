# 차량 변신 뒤 여행지 추천

현재 기본 흐름은 **테마 선택 → 차량 변신 → 오늘은 어디로 가볼까? → 이야기 시작**입니다. 홈 네 테마에는 추천 배지를 표시하지 않습니다.

선택한 테마별로 실제 여행지 3곳을 기기에 포함한 목록에서 보여 줍니다. 여행지 한 곳을 고르고 ‘이야기 시작’을 누르거나 ‘여행지는 나중에 고를래요’로 바로 이야기를 들을 수 있습니다. 진행 중인 이야기를 이어 들을 때는 추천 단계를 반복하지 않습니다.

| 테마 | 기본 여행지 후보 |
| --- | --- |
| 다이노 사파리 | 서울숲, 국립수목원, 설악산 |
| 매직 캐슬 | 롯데월드(서울 송파), 에버랜드(경기 용인), 경주월드(경북 경주) |
| 스페이스 포트 | 국립과천과학관, 영월 별마로천문대, 고흥 나로우주센터 우주과학관 |
| 오션 서브마린 | 해운대해수욕장, 국립해양생물자원관, 경포해수욕장 |

전국의 기본 예시 목록이며 현재 위치 주변 탐색이나 영업·예약 가능 여부를 확인하는 기능은 아닙니다. 네트워크·서버·위치 권한 없이 사용할 수 있습니다. 선택은 이 화면 안의 여행지 선택 표시이며 실제 내비 목적지를 바꾸지 않습니다. 이야기 내용은 테마별 기존 에피소드로 이어집니다.

주차·차량 UX·최신 거리 조건은 기존과 같습니다. 추천 화면에서도 제한 상태가 되면 안전 화면으로 전환하고 자동으로 이야기를 시작하지 않습니다.

기존 목적지 이름→테마 분류기와 보호자 선택 설정은 별도 보조 기능으로 남아 있습니다. 새 기본 여정은 이 설정을 켜거나 여행지를 입력할 필요가 없습니다. 이전 추천 배지 UI 테스트는 과거 흐름의 기록이며 현재 흐름 검증은 DestinationFlowVerification을 사용합니다.
